# Witness Archive – ICE Raids in Chicago Dashboard

This repository contains a Streamlit dashboard for exploring narratives and emotion labels
in reporting on ICE raids in Chicago.

## Project structure

- `app.py` – main Streamlit application
- `corpus.csv.csv` – dataset used by the dashboard
- `requirements.txt` – Python dependencies

## How to run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploying on Streamlit Community Cloud

1. Push this repository to GitHub.
2. Go to Streamlit Community Cloud and create a new app.
3. Select this repo and `app.py` as the entry file.
4. Deploy.
